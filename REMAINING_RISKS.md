# Remaining engineering risks

| ID and severity | Root cause and evidence | Status and reproduction |
|---|---|---|
| R1 High | Privileged experiments execute trusted source, local tc plugins and tools. Several result directories are handed to the initiating UID before root writes additional artifacts. Private daemon control files do not protect those output paths. | Open. Restrict root runs to a trusted checkout and initiating user. In a disposable copy, inspect `owned_directory` in `benchmark.py` and follow the subsequent privileged writes. The next fix is root-owned staging and narrow publication of completed results, followed by splitting the actuator from the daemon. |
| R2 Medium | The C++ actuator waits synchronously for tc, without its own watchdog. Daemon IPC, telemetry and external tc calls share one loop. Sequential timeouts can delay watchdog and clients. | Open. Use a deliberately slow tc stub in a disposable legacy lab, or a slow permitted client and delayed tc in the managed lab. Measure response and cleanup before introducing cancellable actuation or a batching interface. |
| R3 Medium | A trusted external process can keep a namespace alive. Podman enrollment is explicit and scoped, and MPTCP evidence is limited to owned sockets. | Open by design. Keep a process joined to a lab while tearing down holders to demonstrate retained lifetime. Test broader attribution only after specifying isolation and admission ownership. |
| R4 Medium | HTB operations are multi-message. Managed rollback refuses unknown drift, which can leave a partially applied allocation until the operator removes the lab. Classification and borrowing behavior also depend on workload and leaf queues. | Open. `sudo python3 -B tests/adaptive_integration.py` demonstrates refusal under external rate drift. Validate physical-link burst/quantum behavior and run phase-matched capacity trials before claiming a fairness guarantee or adaptive gain. |
| R5 Medium | Benchmark baselines differ by experiment. The historical adaptive unshaped control and the research shaped default impose different load. Fault scenarios censor success-only percentiles, and short repeated windows are correlated. | Open. Reproduce with the manifests in `scenarios/` and compare `ADAPTIVE_RESULTS.md` with `PLATFORM_RESULTS.md`. Predeclare failure and latency gates, freeze a tuned static control, and collect phase-matched repetitions on dedicated hardware. |
| R6 Medium | BPF helper and TCP diagnostic fallbacks differ in visibility. Inventory attributes RTT only for bound sockets and has limited route/link identity and reset detection. | Open. Test churn with ifindex reuse and large TCP tables in a disposable namespace. Use loss counters and independent application samples. No host-wide application latency or MPTCP migration guarantee is inferred. |
| R7 Medium | Local staging cannot verify the systemd sandbox or RPM transactions. There is no release signature or confirmed project-wide license. | Open. `python3 -B tests/install_test.py` validates staged installation and unit syntax. Run actual package install, activation, upgrade and removal on a disposable Fedora VM and add x86_64 privileged coverage. |
| R8 Low | C++ legacy and Python managed controllers retain separate HTB logic. Python still spawns several tool processes per telemetry interval. | Open. Compare `src/main.cpp` and `scripts/adaptive_tc.py` with the execution map in AUDIT.md. Preserve the historical benchmark and measure subprocess cost before extracting shared actuator operations. |
| R9 Low | GitHub CLI reports credential storage in plaintext on the Fedora account. That storage is outside the repository and governed by the user's CLI configuration. | Open. Verify with `gh auth status` without printing the credential. Moving it to a supported keyring is a host configuration task. |
