# Fabric security

## Authorities

The coordinator and agents run unprivileged. The coordinator authenticates client certificate chains and maps exact SHA-256 leaf certificate fingerprints to enrollment or operator identities. The client validates the coordinator certificate chain and DNS SAN. A trusted CA certificate alone cannot enroll an agent. An enrolled agent cannot impersonate another host or perform an operator reconciliation. Telemetry claims are restricted to the enrolled service inventory. Administrative access uses a distinct certificate pin.

The local actuator listens on a filesystem Unix socket in a root-owned directory that is not group or world writable. Socket permissions and SO_PEERCRED restrict calls to the configured agent UID. The agent verifies that the actuator peer is root. The actuator accepts only a scoped, bounded integer cap and enforces local floors, ceilings and generation checks. It requires an explicitly labeled, dedicated interface in a separate network namespace. It owns a fixed HTB root and leaf and checks queue topology and class readback. The wire interface has no raw shell, tc command, path selector, credential distribution or remote capability grant. The isolated root actuator is the only Fabric process that changes queues.

## Replay and persistence

A random current session and strictly increasing sequence bound replay. A new registration invalidates the previous session. TLS resumption tickets are disabled at the coordinator and the protocol does not use early data. The coordinator persists the epoch, generation and pending phase before publishing them. The agent persists the accepted cap before applying it. Both use private single-writer state and atomic rename with fsync. Durability failure stops new policy publication or lease renewal until recovery. Audit events cover enrollment, rejected requests, desired generations, kernel acknowledgements and local fallback. Logs omit session tokens and private key contents.

A coordinator crash leaves qdiscs in place until local watchdogs reduce them to protected floors. A stopped actuator retains its protected cap rather than removing a live budget constraint. If an actuator itself is killed, the last installed qdisc can remain and lease expiry cannot run. A missing actuator stops readback acknowledgement and blocks new increases. For manual recovery, drain that host's traffic and pause further coordination before replacing its test namespace. Inspect kernel state before proceeding. Never reuse an existing root queue by guessing its owner.

## Enrollment and certificate rotation

Generate separate keys for the server, operator and each host. Store keys in operator-managed directories with private file permissions. Calculate pins with `openssl x509 -in leaf.pem -outform DER | sha256sum` and use the hex digest. Pin each client cert to one identity. Use a dedicated trust bundle and short-lived certificates.

For routine client rotation, add the new pin alongside the old pin for that same identity and restart the coordinator with the same state directory. Switch the agent or operator to the new cert and key and verify the new registration, then remove the old pin. Restarting either side may cause a brief fallback. For CA or server rotation, install an overlapping trust bundle at each verifier before switching leaf certificates, retain the expected DNS SAN, then remove the old trust and pins. For suspected compromise remove the affected pin and restart the coordinator promptly. Existing authorized caps expire locally. The implementation does not poll CRLs or OCSP and does not reload TLS files in place.

The enrollment model assumes trusted host operators and honest local agents. Mutual TLS does not attest to kernel state on a compromised host. A stolen agent identity can falsify its own telemetry and acknowledgement, or request caps within its local authority. It cannot cross the configured certificate ACL or Unix privilege boundary under the stated trust assumptions. Duplicate coordinators with copied state or credentials are unsupported. Protect the coordinator state lineage, root actuator configuration, and trusted checkout with local filesystem permissions. Keep the control channel on a management network with a firewall. There is a sixteen-connection handshake limit, but the service is not intended as a public Internet endpoint.
